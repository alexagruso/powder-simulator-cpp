# Powder Simulator

A simple powder physics simulator

## How to run

- Make sure CMake is installed
- run `cmake .` in the root of the project, then `make` in the same directory.
- run `./powdersim` for linux and mac, or `./powdersim.exe` for windows.

## How to use

- Simply left-click anywhere inside the window to spawn new particles, and right-click to delete particles
- Modify `config.txt` to change different settings
